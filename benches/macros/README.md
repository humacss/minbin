# Macro benchmarks

A struct and enum implemented with Minbin's helper macros, with optional Minbin
features disabled.

```sh
cargo bench --bench macros --no-default-features
```

Criterion point estimates from the October 22, 2026 local run with Rust 1.90.0.
All times are nanoseconds per operation.

| Sample | Serialized bytes | Serialize | Deserialize |
|---|---:|---:|---:|
| Struct: `u32` ID and `u64` timestamp | 12 | 9.65 | 11.03 |
| Enum: `Reading(u32)` | 5 | 9.69 | 10.24 |

The struct contains ID 42 and timestamp 123. The enum contains `Reading(42)` and
uses one discriminant byte followed by four payload bytes. This measures the
code generated by the macros, not macro expansion or compilation time.

The [shared harness](../support.rs) prepares byte buffers outside the timed
section, then measures `write_bytes` and `read_bytes` with cleanup included.
Decoded values are constructed through `Default`. The benchmark executable uses
std, while Minbin's std and alloc features remain disabled.

Each case uses a three-second warm-up, five-second measurement window, and 100
samples. Results depend on the machine and load. CI smoke checks validate that
the benchmarks run; they do not enforce performance thresholds.
